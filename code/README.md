# Code Directory

## Files
- `config.py` — label order and default configuration.
- `label_utils.py` — multi-label parsing and validation.
- `split_audit.py` — patient-overlap checks.
- `metrics.py` — multi-label metric calculations.
- `plot_results.py` — training history and evaluation plots.
- `requirements.txt` — key Python dependencies.
- `RUN_GUIDE.md` — how to use the helpers with the Colab notebook.

These are reusable helper scripts. They do not automatically recreate trained
weights or download the dataset. Use the original notebook for the full pipeline.
